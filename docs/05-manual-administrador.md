# Manual administrador (XISTI)

## Acceso

| Campo | Valor |
|-------|--------|
| URL | https://admin.xistiapp.com/admin/login |
| Seed local | Ver `database/seeders/SuperAdminSeeder.php` |

Cambiar contraseña del super admin en el primer acceso a producción.

## Módulos principales

- **Site Settings** — `app_key`, moneda, comisión, flags móviles (`enable_encomiendas_mobile`, etc.)
- **Vehicle Services** — Taxi, Moto, Courier (Rickshaw desactivado para XISTI urbano)
- **Page Settings / Email Templates** — CMS y correos con branding XISTI
- **Usuarios / Conductores** — Gestión operativa
